# 03 — Enforce byte-exact parity and reviewed regeneration

## Context

The acceptance target is the complete 1,048-example suite on main at `101356d`, not 1,048 input files. Three groups perform output or artifact checks: `spec/golden_spec.rb` has 208 examples; `spec/round_trip_golden_spec.rb` has 208 per-fixture cases plus one regression-floor case; and `spec/compat_with_libemf2svg_spec.rb` has 208 Ruby well-formed checks, 208 live-C well-formed checks, nine sampled structural checks, and one aggregate ratio check. The settled 208/209/426 counts must remain intact, but their current skips, pending cases, structural-only checks, and live-C dependency must become explicit hermetic byte contracts.

## Work

- Make all three comparison specs consume the card 01 manifest and reject incomplete, duplicate, or unexpected input/reference sets before examples run.
- Define the oracle for every settled example in the manifest and preserve these exact roles and counts:
  - Golden 208: for each pinned EMF source, compare `Emfsvg.from_file` byte-for-byte with `spec/fixtures/golden/<name>.svg`; that artifact was generated by the manifest-pinned libemf2svg build and is the sole C parity oracle.
  - Round-trip 209: 208 cases read `spec/fixtures/emfsvg_golden/<name>.svg`, convert SVG → EMF → SVG, and compare byte-for-byte with that same emfsvg-generated artifact; the 209th case validates the exact sorted basename/digest inventory for all 208 artifacts. Remove `svg_to_emf_known_divergent.txt`, pending branches, and the mutable `passing` regression floor.
  - Compatibility 426: 208 cases compare current Ruby output directly with the corresponding C-generated `golden` artifact; 208 cases validate each C-generated artifact's bytes against its manifest SHA-256 and provenance; nine cases retain the fixed historical sample but compare Ruby output directly with those same C goldens, with XML structure only as an additional assertion; the final case validates the exact sorted aggregate source/reference/output digest recorded by the manifest instead of an output-size ratio.
- Keep `emfsvg_golden` distinct from `golden`: it is the emfsvg-generated SVG→EMF→SVG input/expected artifact, never evidence of C parity. Ordinary compatibility is fully hermetic and never invokes a live C binary.
- Report mismatches with the comparison group, source basename, reference path, generated digest, and first useful byte/text difference without flooding test output.
- Change regeneration to write all candidate artifacts into a temporary staging directory, fail on any conversion or inventory mismatch, and promote the complete verified set atomically.
- Give each committed baseline its explicit role and provenance above. Fail if the 208-source inventory, either 208-artifact inventory, fixed nine-name sample, or aggregate digest changes without an intentional manifest update.
- Emit a regeneration summary containing pinned revisions, commands, group counts, and changed basenames so intentional changes receive explicit review.
- Keep live libemf2svg comparison as a separate explicit audit. Fix parity failures in the narrowest responsible parser, model, or renderer path rather than regenerating a mismatch away.

## Done when

- The complete suite passes all 1,048 baseline examples plus the new contract coverage on the model-driven path.
- All 208 golden cases compare current Ruby output with the C-generated artifact byte-for-byte; all 208 round-trip conversions compare with their emfsvg-generated source artifact byte-for-byte and their one inventory case proves the complete set; all 426 compatibility cases execute the exact 208/208/9/1 oracle composition above.
- No comparison example is skipped or pending because an input, reference artifact, or live C tool is absent.
- Missing, duplicate, or extra inputs and outputs fail before conversion assertions begin.
- A failed regeneration leaves committed artifacts untouched, while a successful check reports an empty diff and the expected group counts.

```sh
bundle exec rspec spec/parity_manifest_spec.rb spec/golden_spec.rb spec/round_trip_golden_spec.rb spec/compat_with_libemf2svg_spec.rb
bundle exec rspec --dry-run --format progress
bundle exec ruby scripts/regenerate_golden.rb --check
```
